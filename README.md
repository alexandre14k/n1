# n1: bare-metal Rust firmware for NXP LPC1115 (Cortex-M0)

`no_std` Rust firmware for the NXP LPC1111/LPC1114/LPC1115 family on the OM13087 board.<br>
No vendor SDK, no HAL crate, no runtime.

![Visitors](https://api.visitorbadge.io/api/VisitorHit?user=alexandre14k&repo=https://github.com/alexandre14k/n1&label=Views&labelColor=%23555555&countColor=%23007EC6)

## Goal

Resurrect old hardware and make it work on production systems.

Legacy microcontrollers are still deployed, cheap and available.<br>
Their vendor toolchains are not. This project is an attempt to keep<br>
them alive with a small, readable, modern Rust codebase that can be<br>
built, flashed and audited without proprietary tools.<br>

Status: early.<br>
Treat it as a base to harden, not a finished product.

## Features

- Pure Rust, `no_std`, `no_main`
- Own vector table, reset handler and linker script (generated by `build.rs`)
- Register-level drivers: clock, GPIO, timers
- Interrupt-driven events through a lock-free queue
- Flat state machine, no hidden state
- Boot ROM vector checksum patched automatically after build
- Flash with OpenOCD over SWD (CMSIS-DAP)

## Hardware

| Item   | Value                     |
|--------|---------------------------|
| MCU    | NXP LPC1115 (LPC1114 too) |
| Core   | ARM Cortex-M0, thumbv6m   |
| Flash  | 64K (32K on LPC1114)      |
| RAM    | 8K                        |
| Board  | OM13087                   |
| Probe  | CMSIS-DAP, SWD            |

## Requirements

- Linux with bash
- Rust via [rustup](https://rustup.rs)
- Target and tools:

```sh
rustup target add thumbv6m-none-eabi
rustup component add llvm-tools
cargo install cargo-binutils
```

or just use `./make.sh` option `s`

- [OpenOCD](https://openocd.org)

## Build and flash

```sh
./make.sh
```

| Key | Action                          |
|-----|---------------------------------|
| `s` | setup prerequisites             |
| `b` | release build, checksum, export |
| `f` | flash and verify                |
| `e` | erase flash                     |
| `x` | exit                            |

Images are exported to `bin/`.

## Demo behavior

1. Blue LED blinks 100 ms
2. Wait 2 s, green LED blinks 100 ms
3. Wait 1 s, red LED blinks twice (100 ms)
4. Wait 1 s, back to green, forever

Any init failure lights the red LED and halts.

## Layout

```text
src/main.rs        entry
src/app/           state machine, queue, interrupts, pinout
src/hal/           boot, core registers, drivers
src/link/          linker script generator and notes
doc/doc.rst        documentation
make.sh            build, flash, erase
```

## Future development

- Add USART support.
- The on-board programming probe is an LPC11U35. <br>
  For the virtual COM port (VCP), resistors R29 and R30 must be populated.

## Porting

Another LPC111x variant or board needs only:

- a cargo feature for the device
- a device file in `src/hal/core/`
- a pinout file in `src/app/pinout/`
